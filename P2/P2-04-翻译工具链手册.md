## 1. lupdate 帮助

以下是 lupdate 完整帮助，按用途拆成了几段，每段上方有一句中文说明，供查阅；实战例子见帮助后面的 .bat 批量生成脚本（脚本化提取的推荐做法见 P1-07 §2）。

### 用法与简介

```plain
PS D:\zhong_xi\Ultimate_8000\Ultimate_8000> lupdate.exe
Usage:
    lupdate [options] [project-file]...
    lupdate [options] [source-file|path|@lst-file]... -ts ts-files|@lst-file

lupdate is part of Qt's Linguist tool chain. It extracts translatable
messages from Qt UI files, C++, Java and JavaScript/QtScript source code.
Extracted messages are stored in textual translation source files (typically
Qt TS XML). New and modified messages can be merged into existing TS files.

Passing .pro files to lupdate is deprecated.
Please use the lupdate-pro tool instead.
```

上面这段是说：lupdate 是 Qt 语言家（Linguist）工具链的一员，负责从 UI 文件、C++、Java、JavaScript/QtScript 源码中提取可翻译文本，写入 TS（XML）文件；直接向 lupdate 传 .pro 文件的方式已废弃，请改用 lupdate-pro 工具。

### -tr-function-alias（扩展可识别的翻译函数名）

           # += 表示把 <alias> 作为 <function> 的另一种写法也识别；
           # =  表示只把 <alias> 当作 <function> 的唯一写法。

# 2. linguist.exe 使用手册

**lupdate & lrelease** 的使用方法都相对比较简单，但是大部分工作是由 linguist 完成的。对于这个软件的翻译，怎么快速翻译是非常重要的。

linguist 的主界面按"上下文（类名）"分组列出所有待翻译条目——这正是 P1-07 所说的"tr() 以类名为上下文"的直接体现：每个类在左侧面板是一个独立类别，译者逐组完成。

## 2.1 短语书（*.qph）：批量翻译的关键

短语书（*.qph）文件是非常重要的，如果你写好了对应的短语书，那么你可以将短语书的内容批量快速翻译到这些 .ts 文件上。

短语书的使用流程如下：

```
┌──────────────┐   ┌───────────────┐   ┌──────────────┐   ┌──────────────┐
│ 新建短语书    │──▶│ 翻译时 Ctrl+T │──▶│ 编辑→批量翻译 │──▶│ 同步到 .ts   │
│ (*.qph)      │   │ 收藏短语       │   │              │   │ 文件          │
└──────────────┘   └───────────────┘   └──────────────┘   └──────────────┘
```

具体操作（菜单路径）：

1. **创建**：菜单「短语(P) → 新建短语书(N)...」（Ctrl+N），保存为本地 `.qph` 文件；
2. **收藏**：翻译过程中对某条译文按 **Ctrl+T**（或「短语 → 添加到短语书」），把"源文 → 译文"对收进短语书；
3. **批量翻译**：打开短语书后，菜单「编辑 → 批量翻译(B)...」，在对话框中选择要用的短语书并运行——匹配的条目会被自动填上译文（可选"设置翻译过的条目为完成"、"也对已完成的项目做翻译"）。

短语书内容是 XML 格式（linguist 自动生成维护，无需手写），结构如下：

```xml
<!DOCTYPE QPH>
<QPH language="zh_CN">
  <phrase>
    <source>服务地址:</source>
    <target>SERVER ADDRESS:</target>
  </phrase>
  <phrase>
    <source>设备信息:</source>
    <target>DEVICE INFO:</target>
  </phrase>
  <phrase>
    <source>软件版本:</source>
    <target>SOFTWARE VERSION:</target>
  </phrase>
</QPH>
```

工程价值：**术语一致性**。项目里"设备信息"这类术语出现几十次，短语书保证所有 .ts、所有模块里译法统一，也把翻译资产从单个 .ts 文件里解放出来，跨项目复用。

## 3. 小结

```
 工具链手册要点
 ├─ lupdate：-ts 指定输出；-tr-function-alias 扩展识别
 │   自定义翻译函数名；@lst-file 批量传文件清单；
 │   -clang-parser 用 clang 解析（需 compile_commands.json）
 ├─ lupdate 默认可识别的标记：tr / translate / qsTr /
 │   qsTrId / qtTrId / QT_*_NOOP 系列
 ├─ linguist：按上下文（类名）分组翻译；
 │   短语书 Ctrl+T 收藏 → 编辑→批量翻译 → 术语统一
 └─ 批处理脚本化提取见 P1-07 §2
```
