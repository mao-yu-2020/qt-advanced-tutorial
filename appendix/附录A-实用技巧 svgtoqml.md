# 附录 A 实用技巧：svgtoqml（SVG 转 QML）

> 本文基于 **Qt 6.8.3**。界面里的图标资源，除了位图还有一条更优雅的路：
> 把 SVG 矢量图直接转成 QML 代码。

## 工具用法

Qt 自带一个 `svgtoqml` 小工具（在套件 bin 目录下），能把 SVG 图片转换成 QML 渲染代码：

```shell
.\svgtoqml D:\icons\Container.svg TipDeleteRes.qml
```

转换的实质是用 **QML 的声明式绘图代替位图资源**：

```
  SVG 矢量图                QML 代码
 ┌───────────┐  svgtoqml  ┌────────────┐
 │ path/矩形 │  ────────▶ │ Shape +    │
 │ 圆/线条   │            │ ShapePath  │
 └───────────┘            └────────────┘
      ✘ 图片资源文件           ✔ 纯代码，任意缩放不失真
```

## 为什么值得用

- **任意缩放不失真**：矢量描述，高分屏/多分辨率适配的天然解法，省去 `@2x/@3x` 多份位图的管理成本；
- **省资源管理**：图标变成代码，跟着 QML 模块走（P1-10），不用再维护图片资源目录；
- **可绑定**：ShapePath 的 fillColor、strokeWidth 等是 QML 属性，可以参与属性绑定和动画——图标变色、呼吸效果不用换图。

适用边界：图标、简单图形最合适；复杂插画级 SVG 转出的路径量大，需评估渲染开销。
